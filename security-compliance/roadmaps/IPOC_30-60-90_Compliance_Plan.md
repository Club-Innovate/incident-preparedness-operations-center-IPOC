# IPOC 30/60/90 Compliance Plan (HIPAA/HITRUST Readiness)

## Days 0-30 (Baseline and Scope)

- Finalize IPOC compliance profile from template.
- Complete PHI/data inventory and trust-boundary map.
- Confirm control owners and cadence.
- Establish evidence register and storage locations.
- Validate production guardrails (auth validation strictness, exception detail restrictions, telemetry exporter requirements).

### Exit Criteria
- Profile approved.
- Control ownership assigned.
- Evidence register initialized.

## Days 31-60 (Implementation and Evidence)

- Close high-priority control gaps (IAM, auditability, encryption, SDLC scanning, vulnerability SLA).
- Implement/verify retention and disposal controls for logs/data.
- Run first access review and vulnerability review cycle.
- Run tabletop incident response exercise and document outcomes.

### Exit Criteria
- Priority controls implemented.
- First-cycle evidence collected and linked.

## Days 61-90 (Validation and Assessor Readiness)

- Validate control operation with internal testing.
- Remediate exceptions and document compensating controls.
- Compile assessor-ready package (policy + implementation + evidence + test results).
- Define ongoing quarterly governance rhythm.

### Exit Criteria
- Control statuses mostly "Validated" for in-scope set.
- Assessor package draft complete.

## KPI Suggestions

- % controls implemented
- % controls validated
- mean vulnerability remediation time by severity
- % evidence current vs expired
- incident response drill completion rate
