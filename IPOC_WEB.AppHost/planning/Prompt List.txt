Use this prompt set to test against your incident/resource/operations model.
Incident overview
•	“List active incidents and summarize each in one line with priority and current operational period.”
•	“Which incidents are currently at highest risk, and why?”
•	“Show incidents updated in the last 24 hours with key status changes.”
•	“For incident <incidentId>, provide a concise command briefing.”
Objectives / planning
•	“For incident <incidentId>, list current operational objectives and completion status.”
•	“Which objectives are blocked, and what dependencies are missing?”
•	“Summarize objective progress by operational period for incident <incidentId>.”
•	“Recommend top 3 objective priorities for the next period based on current status.”
Tasks / execution
•	“Show open tasks for incident <incidentId> grouped by assignee.”
•	“List overdue tasks with owner, due date, and current status.”
•	“Which tasks are unassigned but high impact?”
•	“Identify task bottlenecks by counting blocked tasks per workstream.”
Resources / logistics
•	“Summarize current resource inventory by location and resource type.”
•	“Show resource shortages where available < committed.”
•	“Which locations have the highest out-of-service resource counts?”
•	“List top 5 constrained resources and impacted incidents.”
Bed availability / capacity
•	“Summarize bed availability by location and bed category.”
•	“Which facilities show occupancy pressure above 85%?”
•	“Show trends in available vs occupied beds for the last 7 days.”
•	“List locations with surge-bed potential and current utilization.”
Communications / notifications
•	“For incident <incidentId>, summarize communication volume and delivery outcomes.”
•	“Which recipients have failed or delayed delivery statuses?”
•	“Show unresolved escalations and their current state.”
•	“Identify communication channels with lowest successful delivery rate.”
Command / ICS structure
•	“List current incident command assignments for incident <incidentId>.”
•	“Which critical ICS positions are vacant right now?”
•	“Show assignment changes in the current operational period.”
•	“Summarize span-of-control concerns by section.”
Audit / governance / quality
•	“Show key operational changes from audit events in the last 48 hours.”
•	“List high-impact updates made outside normal operating hours.”
•	“Identify records with missing required fields affecting reporting quality.”
•	“What data quality issues could skew current readiness reporting?”
RAG reliability prompts
•	“Answer only from indexed records. If data is missing, state exactly what is missing.”
•	“Include source IDs for each major claim.”
•	“Return confidence level (high/medium/low) with a one-line rationale.”
•	“Provide a short answer first, then detailed evidence.”
If needed, a stricter eval set can be provided with expected response format for pass/fail scoring.
